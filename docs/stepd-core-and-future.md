## 한 줄 소개

**긴 방송 영상을 넣으면, AI가 알아서 하이라이트·쇼츠·썸네일까지 만들어 여러 플랫폼에 올리고, 성과와 수익까지 한 화면에서 관리해주는 방송사 전용 콘텐츠 운영 툴.**

---

## 지금 되는 핵심 기능

### 1. AI 하이라이트 추천
긴 회차 영상을 넣으면 AI가 "이 구간을 쇼츠로 만들면 좋다"를 알아서 찾아준다.
- 프로그램 장르(예능·시사·스포츠·뉴스)에 맞춰 자동으로 판단 방식이 바뀜
- 출연자 이름·화면 자막·대사·장면 전환을 모두 함께 보고 결정
- 추천 이유가 함께 표시되므로 운영자가 왜 골랐는지 바로 이해

### 2. 실명 자막 · 화자 구분
- 누가 말하는지 자동으로 구분
- 방송에 뜬 자막(누구누구 · 나이 · 직업)을 읽어 화자 이름을 실명으로 확정
- 결과 자막은 그대로 쇼츠 · 유튜브 자막에 사용 가능

### 3. 어그로 제목 · 클릭베이트 톤
쇼츠 제목을 담백하게 쓰지 않고, 실제 유튜브에서 잘 통하는 톤 (?! · … · 인용문 · 경악 · 임팩트 단어)으로 생성. 방송사가 흔히 놓치는 "일반 시청자용 톤"을 자동 반영.

### 4. 방송사 원본 그대로 쓰는 썸네일
- 이미 만든 방송사 썸네일(공식 완성도 확보됨)에서 얼굴과 제목만 AI로 교체
- 얼굴은 100% 원본 유지 (AI 재생성 없음)
- 제목 문구는 핵심+어그로 조합으로 자동 작성
- 대량 A/B 생성 가능

### 5. 다채널 배포 슬롯
YouTube · Instagram Reels · Facebook · TikTok 4채널에 한 번에 뿌리는 배포 화면 준비 완료.
(실제 자동 송출은 유튜브 우선, 나머지는 순차 오픈)

### 6. 시청자 반응 되먹임
유튜브 댓글에서 "몇 분 몇 초 진짜 웃김" 같은 시청자 지목 구간을 자동 추출 → 다음 추천에 반영. 실제 시청자가 좋아하는 지점을 학습.

### 7. 출연자 사전등록
프로그램별 출연자를 미리 등록해두면 이후 회차에서 자동으로 실명 라벨링. 등록되지 않은 인물은 별도 표시해 사용자 검토 유도.

### 8. 성과 · 수익 대시보드
- 채널·영상·클립별 조회수·구독전환·수익 자동 수집 (유튜브)
- 신규 업로드 48시간 시간별 성과 자동 추적
- 어느 프로그램·출연자·시간대가 잘 되는지 데이터로 확인

### 9. 운영자용 편집 화면
풀스크린 에디터에서 자막·썸네일·컷 편집 → 배포까지 한 흐름. 방송사 조직 워크플로에 맞춘 다크 UI.

## 곧 되는 것 (30~90일)

- **라이브 → 쇼츠**: 방송 나가는 동안 실시간으로 하이라이트 추출
- **제목 먼저, 하이라이트 나중**: 원하는 제목·방향을 먼저 정하면 그에 맞는 구간을 찾아줌
- **프로그램 프롬프트팩**: 프로그램별 톤·금기·시그니처 오프닝을 학습시켜 결과물 통일
- **다회차 하이라이트**: 시즌 전체를 관통하는 스토리·캐릭터·유행어 추적
- **실제 배포 자동화 확장**: 유튜브 외 Instagram · TikTok · Facebook 실송출

## 방송국 B2B 미래

지금은 "쇼츠 제작 도구". 앞으로 가려는 곳은 **방송국 콘텐츠 수익 운영 OS**.

### 확장 5축

| 축 | 무엇을 해주는가 | 방송사 어느 부서용 |
|----|----------------|----------------------|
| **① IP · 프로그램 수익 대시보드** | 프로그램·출연자·코너별 수익을 한 화면에서 | 경영기획 · 미디어사업 |
| **② 광고상품 자동 패키징** | 하이라이트를 브랜드 안전성 판정과 함께 광고상품(중간광고·PPL 슬롯)으로 자동 조립 | 광고영업 |
| **③ 편성 인사이트** | 어떤 코너·시간대·출연자가 재활용에서 강한지 데이터로 편성회의에 제공 | 편성 |
| **④ 아카이브 재활용 엔진** | 과거 방송자산을 오늘의 이슈·트렌드에 맞춰 자동 재큐레이션 | 아카이브 · 홍보 |
| **⑤ 권리 · 승인 흐름** | 출연자·음원·초상권 자동 검출 후 승인 라우팅 | 법무 · 심의 |

### 왜 우리가 유리한가 (데이터 해자)

방송사와 계약이 늘수록 축적되는 자산 — 개인 크리에이터용 도구는 절대 못 쌓는다:

1. **회차 × 성과 페어 데이터** — 어떤 편집이 실제 조회수·수익을 냈는지
2. **프로그램 프롬프트팩 라이브러리** — 방송사별 톤·금기·포맷 지식
3. **출연자 사전** — 얼굴·목소리·별명 매핑
4. **광고주 × 콘텐츠 매칭 이력** — 어떤 세그먼트가 어떤 브랜드에 팔렸는가

## 팔 수 있는 형태 (초기 계약 3안)

1. **채널 운영 SaaS** — 방송사 YouTube 채널 1개 붙이면 추천·편집·배포·성과까지 (월 구독)
2. **회차 처리 종량제** — 회차당 처리비 (자막·하이라이트·썸네일·배포 패키지)
3. **프로그램 프롬프트팩 도입 프로젝트** — 특정 프로그램에 톤·금기 학습 커스텀 (일회성)

계약 후 열리는 것: 방송사 내부 편성 데이터·아카이브 접근·광고영업 시스템 연동 → ①~⑤ 본격 확장.

---

## 우리가 의도적으로 하지 않는 것

- **AI가 결과를 "잘됐다"고 판정하지 않음** — 판단은 언제나 사람 몫, AI는 사실만 리포트
- **얼굴 AI 재생성 금지** — 방송사 신뢰의 근간
- **계약 전 방송사 내부 데이터 요구 금지** — 베타는 외부 공개 데이터만으로 굴러가는 기능만 제공
- **브랜드 로고 임의 생성 금지** — 공식 자산만 사용
