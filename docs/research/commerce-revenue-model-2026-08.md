## 0. 한 줄 결론

> **API가 열린 쪽(쿠팡)은 돈이 안 되고, 돈이 되는 쪽(네이버·유튜브쇼핑)은 전부 수동이다.**
> 그 수동 구간을 자동화하는 것이 제품이고, 우리가 팔 것은 **"어디에 링크를 걸어야 제일 버는지"를 계산해 자동으로 거는 일**이다.

---

## 1. 실제 돈이 나오는 경로 3개 (한국, 2026-08 기준)

| | **쿠팡파트너스** | **네이버 쇼핑 커넥트** | **유튜브 쇼핑 제휴** |
|---|---|---|---|
| **커미션** | **1~3%** (뷰티·패션·스포츠·출산육아 ~3% / 식품·건강·생활 ~2% / 가전·디지털 ~1%). 실사례 실효 **2% 미만** | **직접 3~50%** (셀러 자율 설정) · **간접 1.8%** 고정 | 브랜드가 설정. 업계 평균 **패션·뷰티 5~15%, 전자 2~5%**. 유튜브 플랫폼 수수료 **0원** |
| **인정 조건** | 클릭 후 **24시간** 내 구매 | 구매 확정 기준 | 구매 후 반품 시 취소 |
| **정산** | 실적월 **다다음달 15일**, 최소 1만원, 3.3% 원천징수 | 구매확정월 **다다음달 21일**, 3.3% 원천(법인 부가세 10% 별도) | 구매 후 **60~120일**, **애드센스**로 지급 |
| **자격** | 개인·사업자 모두. **최종승인 = 누적 판매 15만원** | 브랜드 커넥트 가입 + SNS 채널 보유. 2025-07-23 정식출시 | YPP 가입 + 한국 포함 14개국. 일반 요건은 **구독자 500명**(2026-03-30 완화)이나 **쿠팡 상품 태그는 1만명** |
| **자동화(API)** | ✅ **오픈API 있음** — 딥링크·상품검색·골드박스, HMAC SHA256. 단 최종승인 후 발급 | ❌ 크리에이터 대상 **API·자동화 공식 미지원**, 링크 수동 발급 | ⚠️ 공개 API 없음. 스튜디오에 **일괄 태그 추가**만 존재 |
| **치명적 제약** | **검색 API 시간당 10회.** 403 3회면 계정 API 차단 | 자동화 수단 자체가 없음 | 쇼츠는 클릭 버튼이 없어 설명란·고정댓글 의존 |

### 1.1 이 표에서 읽어야 할 것

1. **쿠팡파트너스로는 "돈 번다"가 안 된다.** 실효 2% 미만이면 **100만원어치를 팔아야 2만원**이다.
   여기를 주력으로 잡은 제품은 사용자가 3개월 안에 이탈한다.
2. **돈은 네이버 쇼핑 커넥트에 있다.** 직접 실적 3~50%는 쿠팡 대비 **최대 15배**다.
   유튜브 쇼핑 제휴 도입 후 "수익 20배 증가"(소개팁, 구독 36만) 같은 사례가 나오는 이유가 요율 자체의 차이다.
3. **그런데 돈이 되는 쪽은 API가 없다.** AEDI-V가 굳이 **크롬 확장**으로 만든 이유가 이것이다 —
   서버-투-서버로 태그를 걸 방법이 없으니 브라우저 안에서 사람 손을 대신하는 수밖에 없었다.
4. **쿠팡 검색 API 시간당 10회는 실무에서 못 쓴다.** 영상 1편에 상품 후보 20개면 2시간이 걸린다.
   → **상품 카탈로그를 우리가 미리 색인해 두는 구조가 필수**다. (`core/search/index_segments.py` · `embed.py` 재사용)

## 2. 영상 1편이 실제로 얼마를 버는가 (계산 모델)

> ⚠️ 아래 CTR·전환율은 **공시된 값이 아니라 가정**이다. 실측으로 교체할 자리를 만들어 둔 것.
> 커미션율·정산 조건만 §1의 확인된 값이다.

**전제**: 쇼츠 조회수 10만 · 객단가 3만원 · 상품 카테고리 뷰티

| 단계 | 설명란·고정댓글 링크 (쿠팡) | 유튜브 쇼핑 태그 |
|---|---|---|
| 조회 | 100,000 | 100,000 |
| 클릭 | 클릭 버튼 없음 → **복사·붙여넣기** 필요. CTR 0.3% → **300** | 태그가 클릭 가능. CTR 1.0% → **1,000** |
| 구매 (전환 3%) | 9건 | 30건 |
| 거래액 | 270,000원 | 900,000원 |
| **커미션** | 2% → **5,400원** (3.3% 공제 후 5,222원) | 10% → **90,000원** |

**같은 영상, 같은 콘텐츠인데 경로 선택만으로 17배가 갈린다.**
쇼츠에서 쿠팡파트너스 링크를 설명란에 거는 것은 사실상 수익이 안 나는 조합이고,
이게 시중 툴들이 "많이 만들어서 확률로 때우는" 불펌 대량생산으로 흘러간 이유다.

### 2.1 그래서 우리가 팔 것

**우리는 영상을 더 많이 만드는 툴이 아니라, 영상 1편의 수익을 17배로 만드는 툴이다.**
같은 상품 노출 구간에 대해 세 경로의 기대수익을 계산해서 **제일 높은 경로로 링크를 건다.**
이걸 하는 곳이 지금 없다 — AEDI-V도 쿠팡+유튜브 2개뿐이고 네이버 쇼핑 커넥트는 안 붙어 있다.

## 3. 크리에이터가 실제로 겪는 5단계와, 우리가 가진 것

| # | 단계 | 지금 사람이 하는 일 | STEP D 상태 |
|---|---|---|---|
| 1 | **영상에서 상품 찾기** | 영상 돌려보며 메모 | ✅ **이미 있음** — `core/vision/ppl.py` 가 브랜드·카테고리·노출구간(start/end)·confidence 를 `ppl.json` 으로 출력 |
| 2 | **그 상품의 판매 링크 찾기** | 쿠팡·네이버 검색 노가다 | ❌ 없음 (**상품 카탈로그 레이어**) |
| 3 | **어디에 걸어야 제일 버나 비교** | 아무도 안 함 = 대충 쿠팡 | ❌ 없음 → **우리 킬러 기능(수익 라우팅)** |
| 4 | **링크 발급 + 대가성 문구 + 게시** | 손으로 발급, 설명란 복붙 | 🔶 **절반 있음** — 자동 배포 파이프라인이 이미 유튜브에 올림(`52a6560` 요일·슬롯 규칙). 설명란·고정댓글까지 확장하면 끝 |
| 5 | **성과 회수·재투자** | 파트너스 대시보드 따로 봄 | ❌ 없음 → `subId`(트래킹 파라미터)를 **영상 단위**로 심으면 "어느 영상이 얼마 벌었나"가 바로 나옴 |

**1번과 4번 절반을 이미 갖고 있다.** 새로 만들 것은 2·3·5뿐이고, 그중 3번이 차별점 전부다.

### 3.1 최소 기능 정의 (이것만 되면 돈이 돈다)

```
ppl.json (브랜드·카테고리·구간)
  → [상품 매칭]  사전 색인한 카탈로그에서 SKU 후보 N개
  → [수익 라우팅] 후보 × 3경로 기대수익 = 커미션율 × 객단가 × 경로별 CTR·CVR
                  → 최고 기대수익 경로·상품 선택
  → [링크 발급]  쿠팡: 딥링크 API 자동 / 네이버·유튜브: 사용자 1회 승인 후 저장된 링크 삽입
  → [게시]       기존 배포 파이프라인 + 설명란·고정댓글 + 대가성 문구 자동 삽입
  → [회수]       subId=영상ID 로 영상별 수익 대시보드
```

라우팅 계수(CTR·CVR)는 처음엔 가정값으로 넣고, 5번에서 들어온 실측으로 갱신한다.
**데이터가 쌓일수록 라우팅이 정확해지는 구조** — 이게 후발주자가 못 따라오는 부분이고,
테넌트가 늘수록 좋아지므로 B2B 판매 논리와도 맞는다.

## 4. 돈과 직결된 리스크 (전부 계정 정지 사유)

| # | 리스크 | 대응 |
|---|---|---|
| R1 | **자기 클릭·지인 유도 구매 = 즉시 정지** | 우리 시스템이 검증용 클릭을 **절대** 하지 않도록 못 박을 것. 링크 유효성 검사는 HEAD 요청까지만 |
| R2 | **대가성 문구 누락 = 정지 사유** | "이 영상에는 쿠팡파트너스 활동을 통해 일정 수수료를 제공받을 수 있는 링크가 포함되어 있습니다" **자동 삽입을 기능으로**. 사람이 지울 수 없게 |
| R3 | **네이버 쇼핑 커넥트는 자동화 미지원** | 우리가 링크를 *발급*하지 않고, 사용자가 발급한 링크를 *보관·삽입*하는 구조로 설계. **약관 확인 필요** |
| R4 | **쿠팡 검색 API 시간당 10회 / 403 3회면 차단** | 실시간 조회 금지. 카탈로그 사전 색인 + 캐시. 딥링크 API만 실시간 |
| R5 | **쿠팡 태그는 구독 1만명 이상** | 신설 채널은 유튜브 쇼핑 경로를 못 쓴다. 방송사 테넌트는 대부분 충족 — **B2B가 유리한 또 하나의 이유** |
| R6 | **저작권** (2021-03-22 약관) | 방송·음원·영화 무단 복제·배포·전송 금지, 제재는 **지급 중지 + 자격 상실**. 우리는 고객사 권리 원본만 다루므로 구조적으로 안전 |

## 5. 다음 액션 (순서대로)

1. **쿠팡파트너스 계정 개설 → 최종승인(누적 판매 15만원) → API 키 확보.**
   승인 전에는 API가 안 나온다. **리드타임이 있으니 지금 시작할 것.**
2. **딥링크 PoC** — 기존 `ppl.json` 한 건으로 브랜드→SKU→제휴링크까지 손으로 한 번 관통.
   추가 개발 없이 어디서 끊기는지 확인.
3. **수익 라우팅 비교표** — 실제 영상 3편에 대해 3경로 기대수익을 계산해 표로 만든다.
   §2의 17배 차이가 실제로 재현되면 이 제품은 성립하고, 안 되면 전제를 다시 본다.
4. **네이버 브랜드 커넥트 가입** — 실제 셀러들의 커미션율 분포를 수집.
   "3~50%"의 실제 중앙값이 얼마인지가 §2 계산의 핵심 변수다.
5. **R3 약관 확인** (법무) — 사용자 발급 링크를 SaaS가 보관·자동 삽입하는 구조의 적법성.
