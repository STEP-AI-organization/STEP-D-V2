## Head-to-Head 종합 판단

### ✅ 강점 (편집자 대체 못 하는 것)

1. **스토리 아크 shorts** (40-90s 완결형) — 편집자 style 은 짧은 임팩트 (5-15s) 위주 · 우리는 **narrative-first** 로 서사 있는 shorts 뽑음 → **complementary**
2. **처리 시간 5-10×** — 편집자 5-10h → 우리 30min. **경제 성립**
3. **캐릭터 히스토리 잡음** (#4/17/18) — 대사 문맥 · 편집자가 놓치는 스토리 잡음
4. **홈빵·짜베이 등 밈 감지** (#8/12/20) — 프로그램 톤 학습 잘 됨

### 🟡 약점 (개선 여지)

1. **짧은 임팩트 (5-15s reaction)** 잘 못 뽑음 — 편집자가 매우 잘 뽑는 영역
   - 실 편집자: "소독했다잉" (140K) · "붐치기" (37K) 같은 3-5초 임팩트
   - 우리: 최소 30초+ · 짧은 임팩트 놓침
   - **개선 방향**: shot_types 활용 · shorts_pool 에 5-15s 짧은 임팩트 tier 추가
   
2. **이해 어려운 title** (#2/11) 20% — Gemini title 개선 여지 · 컨텍스트 부족한 caption
   - **개선 방향**: title prompt 에 "타이틀만 봐도 뭔지 알 수 있어야" 강제

3. **뒷담화 회피 룰 없음** (#13 박명수) — 편집자는 다른 방송인 뒷담화 shorts 회피. 우리는 그런 필터 없음
   - **개선 방향**: recommend 프롬프트에 "다른 방송인 부정 언급 회피" 룰 추가

### ❌ 검증 못 한 것 (dependency 있음)

- **실 편집자 blind rating** — 우리 20 + 편집자 5 blind 로 평가. 아직 안 함
- **published CTR** — 실 채널에 publish 해서 baseline 대비 성과. 파일럿 계약 필요
- **adoption rate 실측** — 사용자가 실제 20개 중 몇 개 keep 하는지. 실 사용자 필요
