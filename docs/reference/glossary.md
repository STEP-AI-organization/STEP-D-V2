# 용어집 — 레거시 코드값·배포 코드

> 제품 용어와 콘텐츠 계층의 정본은 [content-model.md](content-model.md)다.
> 이 문서는 기존 코드 enum과 외부 배포 코드의 대응만 기록한다.
> 특히 **클립과 하이라이트는 동의어가 아니다**: 클립은 기본 단위, 하이라이트는 여러 클립의 조합이다.

## 현재 코드값 참고

추천·배포 코드에는 과거 의미의 `short`·`clip` 값이 남아 있다. 이 값은 저장 호환성을 위해 당장 유지하며,
제품 UI와 신규 설계는 `content-model.md`의 롱폼 → 클립 → 숏폼·하이라이트 계층을 따른다.

| 기존 값 | 현재 코드에서의 용도 | 제품 의미로의 정렬 방향 |
|---|---|---|
| `short` | 과거 쇼츠 추천 | 확정 클립에서 생성된 숏폼 파생본 |
| `clip` | 과거 긴 추천 또는 채택 결과 | beat 경계를 보존한 기본 클립 |
| `highlight` | 일부 레거시 경로 | 여러 클립을 참조하는 조합 결과물 |

## 배포용 SMR `clipType`

**배포용 `clipType` (전 9종)** — 정의는 `constants.ts:10-20`. 추천→클립 채택 시 서버가 자동 부여: `apps/server/src/index.ts:506`(adopt 핸들러) `clipType: rec.kind === "short" ? "T6" : "TZ"`. (구 문서가 이 매핑을 "레거시 apps/api"로 표기했으나 오류였다 — 현행 라이브 서버 코드다. apps/api 는 2026-08-12 삭제.)
