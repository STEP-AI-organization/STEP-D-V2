배포 · 시크릿 · 리전

배포 경로

bash deploy/cloud.sh <target> — server(server+render 동시) · worker · gebd · migrate · all. 웹은 deploy-web.ps1(Vercel). 자동배포 트리거 없음 — 수동 gcloud builds submit.

시크릿 (Secret Manager)

stepd-db-url(소켓)·stepd-worker-db-url(TCP)·stepd-google-client-id/secret·stepd-jwt-secret·stepd-public-url·stepd-soniox-api-key. 로컬 .env·gcp-keys/는 gitignore.

리전 배치

컴퓨트·SQL·GCS는 us-central1(비용). AI만 서울 — 얼굴·오디오·자막이 개인정보라 국내 처리. 서울엔 STT Chirp가 없어 전사는 Soniox/Gemini.

접근 통제

Cloud Run은 비공개(IAM) — invoker는 domain:stepai.kr + stepd-deployer SA 뿐. 익명 직행은 403. 공개 면은 Vercel 웹 하나. 신규 서비스 invoker는 관리자 1회 수동.
