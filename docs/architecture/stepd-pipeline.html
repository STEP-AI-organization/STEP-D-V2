화면 자막 읽기 (chyron) — 켜면?

방송 화면 하단의 자막(chyron)을 세그먼트마다 Vision으로 다시 읽어 화자 실명을 붙이는 단계. beat 주석을 flash-lite로 내리며 켜도 흑자가 됐지만, 지금은 원가·단순함 때문에 꺼둔 상태다(켤지는 미결).

이 파이프라인의 규칙

체크포인트 & 재개

단계마다 원자적으로 체크포인트를 쓴다(tmp + os.replace). 실패·재시도 시 완료된 단계부터 다시 시작 — 앞 단계를 다시 사지 않는다. @@PROGRESS로 UI에 단계별 진행률.

사람 몫 / 자동 몫

"전부 자동"이 아니라 사람 부담 최소화. 장르·캐스트 지정은 사람이(정확도), 분석은 파이프라인이. 채택·성공 판정도 사람 몫.

기본 꺼둔 단계

faces·PPL은 기본 OFF(과다검출·시간·원가), env로 켠다 — 코드는 안 지운다. 화면자막(chyron)은 위 비교 참고 — 켜면 +₩440에 인물 검색축이 생긴다.

특화 스코프

드라마·예능 2장르에 집중. 드라마는 화면자막이 약해 캐스트 등록이 선행 필수, 예능은 훅·리액션 중심.
