# 방송국 전사 확장 목표

작성 2026-07-30 · 상태: **전략 목표 / 기능 확장 계획** · 기준 제품: `apps/web` + `apps/server` + `core/`

---

## 0. 한 줄 목표

STEP-D를 **쇼츠 제작 도구**에서 방송국의 **콘텐츠 수익 운영 OS**로 확장한다.

현재 강점은 긴 영상 업로드 → AI 추천 구간 → 운영자 채택 → 클립/쇼츠 편집·배포·성과 추적이다. 다음 목표는 이 흐름을 미디어사업부 안에만 가두지 않고, 광고영업·편성·제작·홍보·아카이브·법무·경영기획이 같은 콘텐츠 데이터와 의사결정 화면을 쓰게 만드는 것이다.

---

## 1. 왜 지금인가

방송국의 핵심 문제는 "쇼츠를 빨리 만드는 것"만이 아니다. 긴 영상 자산을 어떤 플랫폼에, 어떤 패키지로, 어떤 광고상품과 묶어, 어떤 권리 조건 안에서, 어떤 성과 기준으로 재활용할지가 더 큰 문제다.

2026년 업계 방향도 이쪽에 가깝다.

| 근거 | 시사점 |
|---|---|
| [NAB 2026](https://www.nab.org/documents/newsroom/pressRelease.asp?id=7436) | AI가 제작·후반·배포·뉴스룸 워크플로 전반에 들어가고 있음 |
| [IAB 2026 Digital Video Ad Spend](https://www.iab.com/insights/video-ad-spend-report-2026/) | 디지털 비디오 광고비가 2026년 800억 달러를 넘는 시장으로 성장 |
| [Deloitte 2026 Media & Entertainment Outlook](https://www.deloitte.com/us/en/insights/industry/technology/technology-media-telecom-outlooks/media-entertainment-industry-outlook.html) | 미디어사는 audience intelligence와 팬 참여 데이터를 핵심 역량으로 키워야 함 |
| [Deloitte 2026 Digital Media Trends](https://www.deloitte.com/us/en/insights/industry/technology/digital-media-trends-consumption-habits-survey.html) | 뉴스·스포츠 같은 appointment content는 AI 요약·숏폼으로 수명을 연장할 수 있음 |

즉 STEP-D의 다음 경쟁력은 AI 편집 자체보다 **수익화, 편성 판단, 권리 안전성, 자산 재활용, 조직 승인 흐름**이다.

## 4. 기능 확장 우선순위

### 4.1 광고영업 / 수익 기능

목표: STEP-D를 "콘텐츠팀 편집툴"에서 "광고영업팀 매출툴"로 확장한다.

필수 기능:
- 클립별 예상 광고가치, CPM/RPM, 조회수, 전환 성과
- 프로그램/IP별 수익 대시보드
- 광고주 제안서 자동 생성
- 캠페인별 클립 패키징: 예) 이번 주 예능 하이라이트 20개 + 숏폼 50개
- 브랜드 세이프티, 금칙어, 출연자/장면 리스크 체크
- 광고주 리포트 PDF/XLSX export

성공 기준:
- 광고주 제안서 1건 생성 시간이 1일 이상 → 30분 이하
- 프로그램/IP 단위 수익 리포트를 주간 회의에서 사용
- 광고영업팀이 직접 STEP-D에 로그인

### 4.2 편성 / 전략 기능

목표: 숏폼 성과를 본방·재방·OTT·디지털 편성 판단으로 되돌린다.

필수 기능:
- 프로그램별 숏폼 반응 → 본방/재방/OTT 편성 참고
- 회차별 후킹 포인트 분석
- 장르/출연자/코너별 성과 비교
- YouTube/Meta/SMR/OTT/방송 성과 통합 비교
- 다음 주에 밀어야 할 장면·출연자·코너 추천

성공 기준:
- 편성/전략 회의용 주간 리포트 자동 생성
- 프로그램·코너별 성과 비교 화면 제공
- "조회수"뿐 아니라 유지율·댓글·공유·광고가치까지 복합 점수화

### 4.3 아카이브 / MAM-lite

목표: 방송국의 오래된 영상 창고를 검색 가능한 수익 자산으로 바꾼다.

필수 기능:
- 방송국 기존 영상 자산 검색
- STT, 얼굴/이름 OCR, 장면 태그, 출연자 태그
- 인물·프로그램·코너·시즌·키워드 기반 검색
- 과거 3년간 명절/시즌/특정 출연자 장면 검색
- 기존 장기 영상에서 재활용 가능한 숏폼 후보 추천

성공 기준:
- 자료 요청 처리 시간이 수시간 → 수분 단위로 감소
- 과거 영상 기반 재활용 클립이 월간 일정 비율 이상 발생
- 아카이브 검색 결과에서 바로 추천/편집/배포 흐름으로 이동

### 4.4 권리 / 법무 / 승인 워크플로

목표: 엔터프라이즈 방송국 도입에 필요한 안전장치를 만든다.

필수 기능:
- 음악, 출연자, 스포츠 중계권, 지역 제한, 기간 제한 관리
- 클립 단위 권리 상태: 사용 가능 / 확인 필요 / 금지
- 배포 전 승인 플로우: PD → 법무/심의 → 홍보 → 배포
- 역할 권한, 감사 로그, 조직별 접근 제어
- SSO와 계정 수명주기 관리

성공 기준:
- 권리 미확인 클립의 외부 배포 차단
- 모든 배포 이력에 승인자·시각·버전 로그 기록
- 방송국 보안/법무 심사 통과 가능 수준의 감사 체계 확보

### 4.5 홍보 / 마케팅 기능

목표: 프로그램 홍보팀이 매일 쓰는 콘텐츠 운영 캘린더가 된다.

필수 기능:
- 프로그램별 콘텐츠 캘린더
- 티저/본방/비하인드/하이라이트 자동 패키지
- 출연자별 SNS용 클립 묶음
- 댓글/반응/커뮤니티 여론 요약
- 팬 세그먼트별 추천 소재

성공 기준:
- 홍보 캠페인별 소재 현황을 STEP-D에서 관리
- 출연자/프로그램별 홍보 클립 묶음 자동 생성
- 팬 반응 요약이 다음 홍보 액션으로 이어짐

## 6. 제품 원칙

1. **편집보다 의사결정이 상위다.**
   STEP-D의 확장 가치는 더 예쁜 편집기가 아니라 어떤 콘텐츠를 어디에 팔고 밀어야 하는지 판단하게 해주는 데 있다.

2. **부서별 화면은 달라도 데이터 계보는 하나다.**
   원본 영상 → 분석 → 추천 → 채택/거절 → 편집 결정 → 배포 → 성과 → 수익/권리/승인 로그가 끊기면 안 된다.

3. **권리와 승인 없는 배포 자동화는 엔터프라이즈에서 위험하다.**
   실제 송출 기능보다 먼저 권리 상태, 승인자, 감사 로그를 설계한다.

4. **방송국의 과거 영상은 비용이 아니라 자산이다.**
   아카이브 검색과 재활용 후보 추천은 장기 락인의 핵심이다.

5. **경영진 화면은 조회수가 아니라 수익과 효율을 보여야 한다.**
   조회수, 유지율, 공유, 댓글, 광고가치, 제작 시간, 배포량을 IP 단위로 묶어야 한다.

| 사용자 확장 | 미디어사업부 외 로그인 부서 수, 부서별 주간 활성 사용자 |
| 수익 연결 | 광고주 제안서 생성 수, 캠페인 매출 기여, IP별 수익 리포트 사용 횟수 |
| 운영 효율 | 회차당 숏폼 제작 시간, 자료 검색 시간, 승인 리드타임 |
| 품질/안전 | 권리 미확인 배포 차단 수, 배포 사고 0건, 승인 로그 완성률 |
| 락인 | 아카이브 인덱싱 영상 수, 재활용 클립 수, 프로그램별 누적 컨텍스트 자산 |

## 8. 구현 관점의 다음 문서화 필요 항목

이 문서는 목표 문서다. 실제 구현 전에 아래 하위 계획이 필요하다.

| 하위 문서 | 내용 |
|---|---|
| 광고영업/수익 대시보드 설계 | 수익 데이터 모델, 리포트 export, 광고주 제안서 템플릿 |
| 권리/승인 워크플로 설계 | 상태 머신, 역할 권한, 감사 로그, 배포 게이트 |

## 9. 최종 목표 상태

방송국 안에서 STEP-D는 다음 질문에 답하는 시스템이 되어야 한다.

- 이번 주 어떤 프로그램/IP가 가장 돈이 되는가?
- 어떤 장면을 숏폼·광고상품·홍보 소재로 밀어야 하는가?
- 어떤 출연자·코너·장르가 플랫폼별로 반응하는가?
- 이 클립은 권리와 심의상 배포 가능한가?
- 과거 영상 중 지금 다시 쓸 수 있는 자산은 무엇인가?
- 어떤 콘텐츠가 광고영업 제안서와 편성 판단으로 이어졌는가?

이 상태가 되면 STEP-D는 단순 제작툴이 아니라 방송국의 콘텐츠 자산과 수익 의사결정이 쌓이는 시스템이 된다.
