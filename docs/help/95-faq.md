화면별 안내는 각 문서에 있습니다. 여기는 **어느 화면인지 모를 때** 보는 목록입니다.

## 로그인 · 계정

**로그인이 안 됩니다**
→ 계정은 초대로만 만들어집니다. 회원가입은 없습니다. 워크스페이스 관리자에게 초대를
요청하세요.

**초대 링크가 안 열립니다**
→ 링크에는 사용 기한이 있습니다. 관리자에게 다시 보내 달라고 하세요.

**결제 메뉴가 안 보입니다**
→ 멤버 권한입니다. 결제와 팀원 관리는 소유자·관리자만 할 수 있습니다.

## 영상이 안 돕니다

**업로드했는데 분석이 시작을 안 합니다**
→ 업로드 ≠ 분석입니다. 분석을 따로 요청해야 합니다.
이미 요청했다면 상태가 「분석 보류」인지 보세요 — 대개 **크레딧 부족**입니다.
충전 후 「다시 시도」를 눌러야 시작됩니다.

**분석이 끝났는데 만들어진 영상이 없습니다**
→ 추천 구간을 **채택**해야 영상이 만들어집니다. 분석 완료는 추천 목록이 나온 것까지입니다.

**추천 구간이 하나도 없습니다**
→ 말소리가 거의 없거나 아주 짧은 영상일 수 있습니다. 회차 상세에서 받아쓰기 결과가
비어 있지 않은지 확인하세요.

**인물 이름이 "출연자 1" 로만 나옵니다**
→ 프로그램에 출연진이 등록되지 않은 상태로 분석된 것입니다. 등록 후 재분석하면 붙습니다
(크레딧이 다시 듭니다).

## 배포가 안 됩니다

**배포했는데 채널에 영상이 없습니다**
→ 배포 화면에서 상태를 보세요.
「기록만」 = 실제 업로드가 꺼져 있음 · 「예약」 = 아직 공개 시각 전 · 「실패」 = 사유 확인 후 재시도.

**실패한 배포가 저절로 다시 안 갑니다**
→ 의도된 동작입니다. 셀을 눌러 「다시 시도」 하세요.

**계정 연결이 끊겼다고 나옵니다**
→ 배포 채널 화면에서 다시 연결하세요. 「토큰 만료 임박」 경고가 보이면 미루지 마세요.

## 자동 배포가 안 나갑니다

이 순서로 보세요.

1. **크레딧 잔액** — 0이면 전부 멈춥니다.
2. **활동 시간대 · 발행 요일** — 지금이 정한 시간·요일인지.
3. **승인 대기** — 「승인 후 게시」로 설정했다면 사람이 승인해야 나갑니다.
4. **오늘 할당량** — 이미 오늘 몫을 다 보냈을 수 있습니다.
5. **새 회차** — 처리할 원본이 없으면 만들 것도 없습니다.

자동 배포 화면이 지금 어느 사유로 쉬고 있는지 적어 줍니다.

## 숫자가 이상합니다

**성과 숫자가 0입니다**
→ 유튜브 집계에 시간이 걸립니다. 방금 올린 영상은 한동안 0입니다.
그리고 그 채널이 **분석용으로 연결**돼 있어야 지표가 들어옵니다.

**어제 본 숫자와 오늘 숫자가 다릅니다**
→ 유튜브가 최근 며칠 치를 다시 계산합니다. 정상입니다.

## 화면이 비어 있습니다

**목록이 통째로 비어 보입니다**
→ 데이터가 없는 것인지 서버 연결이 끊긴 것인지 구분해야 합니다.
연결이 끊겼으면 화면 위에 안내 띠가 뜹니다. 띠가 없는데 비어 있다면 실제로 데이터가
없는 것입니다.

## 그래도 안 될 때

**운영 진단** 화면에서 지금 작업이 몇 건 돌고 어디서 막혔는지 볼 수 있습니다.
그 화면의 내용을 함께 알려 주시면 훨씬 빨리 확인할 수 있습니다.
