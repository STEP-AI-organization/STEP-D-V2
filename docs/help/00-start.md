## 워크스페이스란

워크스페이스는 **우리 회사 전용 공간**입니다. 프로그램·영상·채널 연결·크레딧이 모두 이 안에
들어 있고, 다른 회사의 자료는 어떤 경우에도 보이지 않습니다.

## 로그인

계정은 **초대로만** 만들어집니다. 회원가입 화면은 없습니다.

1. 초대 메일의 링크를 엽니다.
2. 이름과 비밀번호를 정합니다.
3. 다음부터는 이메일 + 비밀번호로 로그인합니다.

초대 메일을 못 받았다면 워크스페이스 관리자에게 다시 보내 달라고 요청하세요. 링크에는
사용 기한이 있어서, 오래된 메일의 링크는 열리지 않습니다.

## 팀원 권한 3가지

| 역할 | 할 수 있는 일 |
|------|---------------|
| **소유자(owner)** | 전부. 팀원 초대·삭제, 결제 수단 등록, 워크스페이스 이름 변경 |
| **관리자(admin)** | 소유자와 거의 같습니다. 팀원 초대와 결제까지 가능 |
| **멤버(member)** | 영상 올리기·분석·편집·배포 등 실무 전부. **결제와 팀원 관리는 불가** |

팀원 초대는 워크스페이스 설정에서 소유자·관리자가 합니다.

## 전체 흐름 — 영상 한 편이 지나가는 길

```
① 프로그램 만들기        방송 시리즈 하나를 등록하고 출연진을 미리 적어 둡니다
② 회차 원본 올리기       긴 영상(한 편 전체)을 올립니다
③ AI 분석                볼 만한 구간을 찾아 추천으로 올려 줍니다
④ 채택                   쓸 구간만 고릅니다 → 숏폼·클립이 만들어집니다
⑤ 편집                   자막·제목·템플릿을 다듬습니다
⑥ 배포                   유튜브·인스타그램·틱톡·네이버로 내보냅니다
⑦ 성과 확인              조회수·시청시간을 봅니다
```

②~⑥을 사람이 매번 누르지 않고 자동으로 돌리는 것이 **자동 배포**입니다.

## 처음이라면 이 순서로

1. **프로그램**에서 프로그램 하나를 만들고 출연진을 등록합니다.
   → 인물 이름이 정확히 붙는지가 여기서 갈립니다.
2. **배포 채널**에서 유튜브 채널을 연결합니다.
3. **영상 분석**에서 회차 원본을 하나 올려 분석을 돌려 봅니다.
4. 추천 구간이 나오면 마음에 드는 것만 채택합니다.
5. **미디어**에서 만들어진 영상을 확인하고 배포합니다.

여기까지 한 번 돌려 본 다음에 **자동 배포**를 켜는 것을 권합니다. 자동 배포는 이 과정을
그대로 무인으로 돌리는 기능이라, 수동으로 한 번 겪어 보면 설정 항목이 훨씬 잘 읽힙니다.

## 대시보드에서 보이는 것

로그인하면 처음 열리는 화면입니다. 최근 배포, 채널별 순위, 수익 요약이 있습니다.
숫자가 비어 있다면 아직 배포한 영상이 없거나, 채널 연결이 안 된 것입니다.
