## 이 화면에서 하는 일

영상에서 찾아낸 **상품 링크를 사람이 검토**하는 자리입니다.
승인한 것만 발행 설명란에 붙습니다.

## 어떻게 도나

```
① 영상에서 상품 후보를 찾습니다
② 링크를 발급합니다
③ 사람이 이 화면에서 확인합니다   ← 여기가 관문
④ 승인한 것만 설명란에 붙어 나갑니다
```

**발급 ≠ 게시입니다.** 링크가 만들어졌어도 승인 전에는 어디에도 나가지 않습니다.
기본 상태는 '검토 대기' 입니다.

## 검토할 때 보는 것

- 영상 내용과 상품이 실제로 맞는지
- 상품이 판매 중인지
- 우리 채널에 붙여도 되는 상품인지

맞지 않으면 승인하지 않거나 상품을 교체합니다. 링크를 다시 발급할 수도 있습니다.

## 승인하면 붙는 것

승인한 링크는 발행 시 **설명란에 링크 + 대가성 안내 문구**와 함께 붙습니다.
안내 문구는 자동으로 들어갑니다 — 따로 쓰지 않아도 됩니다.

## ⚠️ 생성된 링크를 직접 누르지 마세요

제휴 링크는 **본인이 클릭하면 계정이 정지될 수 있습니다.**
확인이 필요하면 링크를 열지 말고 상품명으로 검색해서 보세요.

## 이 기능이 안 보인다면

상품 링크는 워크스페이스별로 켜고 끕니다. 메뉴는 보이는데 아무것도 안 쌓인다면
아직 꺼져 있는 것입니다. 담당자에게 문의하세요.

## 자주 막히는 곳

**검토 대기 목록이 비어 있습니다**
→ 기능이 꺼져 있거나, 아직 상품이 발견된 영상이 없는 것입니다.

**승인했는데 설명란에 안 붙었습니다**
→ 승인은 **다음 발행부터** 적용됩니다. 이미 올라간 영상의 설명은 배포 화면에서 직접
수정해야 합니다.
