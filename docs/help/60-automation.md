## 자동 배포란

프로그램·채널·요일·시간을 정해 두면 **분석부터 배포까지 사람 없이** 돕니다.
새 회차가 올라오면 알아서 분석하고, 좋은 구간을 골라 영상을 만들고, 정한 시각에 올립니다.

설정 단위를 **계획**이라고 부릅니다. 계획은 여러 개 만들 수 있습니다.

## 계획에서 정하는 것

| 항목 | 설명 |
|------|------|
| **프로그램** | 어느 프로그램을 대상으로 할지. 여러 개 고를 수 있습니다 |
| **채널** | 어디에 올릴지. 여러 개 고를 수 있습니다 |
| **요일** | 어떤 요일에 발행할지. 비워 두면 매일입니다 |
| **시각 슬롯** | "17:00, 20:00" 처럼 정각을 지정합니다. 그 시각이 지나야 그만큼 나갑니다 |
| **활동 시간대** | 슬롯을 안 쓸 때. 기본 9시~22시. 이 밖에는 안 올립니다 |
| **하루 할당량** | 채널당 하루 몇 건까지. 기본 3건 |
| **승인 방식** | 사람이 승인한 뒤 게시 / 승인 없이 바로 게시 |
| **영상 방향** | 세로(숏폼) / 가로(클립) |
| **세로 배치** | 레터박스 · 꽉 채우기 · 인물 중심 · 보조 화면 |
| **템플릿·자막** | 틀, 자막 켜기/끄기, 자막 위치·크기·색, 로고·제목·시간박스 표시 |
| **썸네일 방식** | 영상 프레임 / AI 생성 (AI는 출연진 등록 필요) |

## 슬롯과 할당량 — 둘 중 하나로 돕니다

- **슬롯을 정하면**: 그 시각이 지날 때마다 한 건씩 나갑니다.
  17:00·20:00·22:00 로 잡았고 지금이 20:30이면 오늘 누적 2건까지입니다.
- **슬롯을 비우면**: 활동 시간대 안에서 할당량을 채울 때까지 계속 나갑니다.

정해진 시각에 규칙적으로 올리고 싶으면 슬롯을, 시간대 안에서 빨리 소진하고 싶으면
할당량 방식을 쓰세요.

## 승인 방식

- **승인 후 게시** — 만들어진 영상이 승인 대기로 쌓입니다. 사람이 확인하고 승인해야 나갑니다.
- **승인 없이 게시** — 조건을 통과하면 바로 나갑니다.

승인 대기 중인 건수는 자동 배포 화면 위쪽에 표시됩니다.

## 왜 안 나가나 — 사유를 화면이 알려 줍니다

계획이 켜져 있는데 아무것도 안 나갈 때, 화면이 그 이유를 적어 줍니다.
자주 나오는 것들:

| 사유 | 뜻 | 할 일 |
|------|-----|------|
| 활동 시간대 밖 | 지금은 정한 시간이 아님 | 기다리거나 시간대를 넓힙니다 |
| 발행 요일 아님 | 오늘은 정한 요일이 아님 | 요일 설정을 확인합니다 |
| 새 회차 없음 | 처리할 원본이 없음 | 회차를 올립니다 |
| 분석 중 | 분석이 도는 중 | 기다립니다 |
| 분석 보류 | 분석이 시작을 못 함 | **대개 크레딧 부족**입니다 |
| 오늘 할당량 채움 | 오늘 몫을 다 보냄 | 내일 다시 돕니다 |
| 승인 대기 | 사람 승인을 기다림 | 승인합니다 |
| 실제 업로드 꺼짐 | 기록만 되는 상태 | 담당자에게 해제 요청 |
| 렌더 대기 | 영상 만드는 중 | 기다립니다 |

## 리포트 메일

하루 몫이 다 나가면 **묶어서 한 통**으로 결과 메일이 갑니다. 영상마다 오지 않습니다.
받을 사람은 자동 배포 화면에서 등록합니다. 여러 명 등록할 수 있습니다.

이 설정은 계획별이 아니라 **워크스페이스 단위**입니다 — 어느 계획이 보내든 같은 사람이
받습니다.

## 잠깐 멈추기 · 지우기

- **일시정지** — 계획을 남겨 두고 멈춥니다. 다시 켜면 이어서 돕니다.
- **삭제** — 계획을 지웁니다. **이미 올라간 영상은 내려가지 않습니다.**
  필요하면 채널에서 직접 내려야 합니다.

## 자주 막히는 곳

**계획을 켰는데 하루 종일 아무것도 안 나갔습니다**
→ 화면의 사유를 먼저 읽으세요. 가장 흔한 순서는 ① 크레딧 부족 ② 활동 시간대·요일 ③ 승인 대기입니다.

**크레딧이 0이 되면 어떻게 되나요**
→ 분석이 시작되지 않아 **그 뒤 전부가 멈춥니다.** 충전하면 다음 순회부터 다시 돕니다.

**하루에 더 많이 올리고 싶습니다**
→ 할당량을 올리거나 슬롯을 늘립니다. 다만 회차 하나에서 나오는 영상 수에 한계가 있어,
계획만 늘린다고 그만큼 나오지는 않습니다. 원본 회차가 더 필요합니다.

**같은 영상이 두 채널에 똑같이 올라갑니다**
→ 계획이 여러 채널을 포함하면 그렇게 됩니다. 채널마다 다른 영상을 원하면 계획을 나누세요.
