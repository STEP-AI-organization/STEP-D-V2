# 제목 그래픽 자산 (.mogrt)

여기에 **`stepd-title.mogrt`** 를 두면 프리미어 패널이 자동으로 받아 쓴다
(`https://stepd.stepai.kr/mogrt/stepd-title.mogrt`). 편집자는 아무것도 만들지 않는다 —
폰트와 같은 방식이다.

## 왜 파일이 필요한가

UXP 에는 "텍스트를 만들고 글꼴·색을 지정" 하는 API 가 **없다.** 있는 건 미리 만들어 둔
모션 그래픽 템플릿을 꽂는 `insertMogrtFromPath` 뿐이다. 그래서 이 파일만은 프리미어에서
사람이 한 번 저장해야 한다 — 대신 그 "한 번" 은 **편집자마다가 아니라 우리가 한 번**이다.

## 만들 때 반드시 지킬 것

1. 텍스트 레이어 **둘** (1행 = 흰색 setup · 2행 = 강조색 payoff)
2. 글꼴 **Gmarket Sans TTF · Bold**
3. ⚠️ **필수 그래픽 패널에서 "컨트롤로 노출"** — 최소 셋:
   1행 텍스트 · 2행 텍스트 · **2행 색상**
4. 세로 쇼츠(1080×1920) 기준으로 위치를 잡는다 (제목 세로 위치 ≈ 화면 11%)

**3번을 빼먹으면 값이 파일 안에 박제된다.** 그러면 서버에서 강조색을 바꿔도 프리미어 경로만
옛 색으로 남는다 — 같은 프로그램 쇼츠가 경로에 따라 달라지고, 고객은 "일관성이 없다" 고 본다.
값의 정본은 `GET /api/programs/:id/shorts-style` 이고, 패널이 삽입 시점에 채워 넣는다.

## 파라미터 이름

우리가 정할 수 없다(만드는 사람이 정한다). 패널은 이름으로 **찾고**, 못 찾으면 실제 목록을
UDT 콘솔에 `[STEP-D] mogrt params: …` 로 쏟는다. 처음 한 번 그 로그를 보고 맞추면 된다.
