# 썸네일 스타일 프로파일 (참고 이미지 기반)

> AI 분석 자동 생성 · Planner 프롬프트 주입용

## 프로그램 정체성
- 장르: 리얼리티 연애
- 로고 위치: 채널 로고 우상단, 프로그램 로고 좌상단
- 로고 스타일: 프로그램 로고는 흰색 텍스트, 채널 로고는 흰색 텍스트

## 구도
- 지배적 레이아웃: 좌우 이등분 (전면 인물), 중앙 배경
- 인물 배치: 주요 인물 2명 좌우 전면에 배치, 다수 인물 후면 배치
- 인물 수: 2명 (전면), 5명 이상 (후면)
- 얼굴 크기: 얼굴이 화면 세로 길이의 약 1/3~1/2 차지
- 배경: 실제 촬영 현장 배경 유지, 전면 인물 강조를 위해 살짝 블러 처리

## 감정 · 대비
- 표정: 놀람, 미소, 긴장
- 대비 방식: 주요 인물 간 표정 대비 (놀람 vs 미소), 전면 인물과 후면 배경의 명확한 분리
- 색: 스킨톤, 블랙, 화이트, 밝은 청록색, 핑크

## 자막 계층
- 프로그램 로고
- 반응 배지
- 인용문
- 메인 카피

- 메인 카피: 하단 전체 너비, 굵고 큰 고딕체, 밝은 청록색 바탕에 흰색 테두리/그림자, 좌측 정렬
- 인용문: 흰색 손글씨체, 따옴표 사용, 인물 근처 배치
- 배지: 핑크색 손글씨체, 인물 상단/측면 배치
- 어조: 사건 명시, 궁금증 유발, 인물 감정 직접 인용
- 폰트: 메인 카피는 두꺼운 고딕 계열, 인용문 및 배지는 손글씨 계열

## Planner 실전 지시
1. 메인 인물 2명을 좌우에 크게 배치하고, 배경은 실제 촬영 현장을 살리되 살짝 블러 처리하여 인물에 집중시킨다.
2. 메인 인물들의 표정은 상반된 감정(예: 미소 vs 놀람)을 명확히 보여주도록 한다.
3. 메인 자막은 하단에 크게, 밝은 청록색과 같은 눈에 띄는 색상, 두꺼운 고딕체로 배치한다.
4. 인용문은 흰색 손글씨체로 인물 옆에 배치하여 현장감을 살린다.
5. 감탄사/반응 자막은 핑크색 손글씨체로 인물 머리 위나 옆에 배치하여 생동감을 더한다.
6. 프로그램 로고는 좌상단, 채널 로고는 우상단에 작게 배치한다.
7. 전반적으로 밝고 선명한 색감을 사용하여 시청자의 시선을 끈다.
